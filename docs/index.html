설치

  1. 01

    ZIP 압축 해제

    다운로드한 파일을 폴더에 풀어 주세요.

  2. 02

    확장프로그램 관리 열기

    브라우저 주소창에 아래 주소를 입력하세요.

    Chromechrome://extensions
    Edgeedge://extensions
  3. 03

    폴더 불러오기

    개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누르세요.
    manifest.json이 들어 있는 폴더를 선택한 뒤 디시 글쓰기 페이지를 새로고침하세요.

설치한 폴더는 삭제하지 마세요.

사용 방법

특이점 갤러리 글쓰기 ↗

01 글쓰기 화면에서 HTML 모드 끄기

편집기 오른쪽 위의 HTML 체크를 해제하고, 본문에서 이미지를 넣을 위치를 선택하세요. 기본 말머리 안내문은 자동으로 정리됩니다.

02 이미지 업로드 누르기

본문 위에서 이미지 업로드를 누르세요.

03 이미지 선택 후 디시에서 등록

새 창에서 이미지를 선택하세요를 누르세요. 여러 장을 선택할 수 있습니다.
업로드 후 본문을 확인하고 디시의 인증·등록 절차를 진행하세요.

문제 해결

‘삽입 다시 시도’를 눌러야 들어감
v1.0.3에서 첫 삽입의 커서 오류를 수정했습니다. 최신 ZIP으로 교체한 뒤 확장과 글쓰기 페이지를 새로고침하세요.
업로드 뒤 새 글쓰기 창만 열림
최신 ZIP으로 교체하고 확장 관리 화면과 원래 글쓰기 페이지를 새로고침하세요.
업로드 창이 열리지 않음
디시 글쓰기 페이지에서 팝업을 허용한 뒤 다시 누르세요.
이미지가 본문에 들어오지 않음
직접 링크로 넣기(자동 삽입이 안 될 때)를 열어 Postimages의 ‘직접 링크’나 ‘포럼용 핫링크’를 붙여 넣으세요.
확장프로그램 업데이트
작성 중인 본문을 먼저 복사해 보관하세요. 새 ZIP으로 기존 폴더의 파일을 교체하고, 확장프로그램 관리 화면과 디시 페이지를 새로고침하세요.
