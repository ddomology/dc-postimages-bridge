다운로드 및 설치

디시 글쓰기 화면에 Postimages 이미지 업로드 버튼을 추가합니다.

확장프로그램 다운로드 ↓ZIP · 압축 해제 후 설치
설치사용 방법문제 해결

설치

  1. 01

    ZIP 압축 해제

    다운로드한 파일을 폴더에 풀어 주세요.

  2. 02

    확장프로그램 관리 열기

    브라우저 주소창에 아래 주소를 입력하세요.

    Chromechrome://extensions
    Edgeedge://extensions
  3. 03

    폴더 불러오기

    개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누르세요.
    manifest.json이 들어 있는 폴더를 선택한 뒤 디시 글쓰기 페이지를 새로고침하세요.

설치한 폴더는 삭제하지 마세요. Tampermonkey는 필요하지 않습니다.

사용 방법

특이점 갤러리 글쓰기 ↗

01 글쓰기 화면에서 HTML 모드 끄기

편집기 오른쪽 위의 HTML 체크를 해제하고, 본문에서 이미지를 넣을 위치를 선택하세요.

02 Postimages 이미지 업로드 누르기

설치 후 본문 위에 표시되는 도우미에서 Postimages 이미지 업로드를 누르세요.

03 이미지 선택 후 디시에서 등록

새 창에서 이미지를 선택하세요를 누르세요. 여러 장을 선택할 수 있습니다.
업로드 후 본문을 확인하고 디시의 인증·등록 절차를 진행하세요.

문제 해결

업로드 창이 열리지 않음
디시 글쓰기 페이지에서 팝업을 허용한 뒤 다시 누르세요.
이미지가 본문에 들어오지 않음
도우미의 직접 링크로 넣기를 열어 Postimages의 ‘직접 링크’나 ‘포럼용 핫링크’를 붙여 넣으세요.
확장프로그램 업데이트
새 ZIP으로 기존 폴더의 파일을 교체하고, 확장프로그램 관리 화면과 디시 페이지를 새로고침하세요.
지원 범위와 검증 상태

PC Chrome·Edge의 글쓰기 화면용입니다. 모바일·글 수정 화면은 지원하지 않습니다.

로직 테스트 8개, 실제 Summernote 기반 로컬 테스트 12개를 통과했습니다. 실제 확장 설치·파일 업로드·디시 게시 후 이미지 표시까지의 검증은 남아 있습니다.

이미지는 Postimages에 저장되며 링크를 아는 사람이 볼 수 있습니다. 확장은 디시 쿠키·비밀번호를 수집하지 않습니다. 최종 글 등록은 사용자가 진행합니다.

디시인사이드·Postimages와 제휴하지 않은 비공식 도구입니다.
