v1.0.0 · ZIP 압축해제 설치 · Tampermonkey 불필요

한 번 설치하면 준비 끝

  1. 다운로드한 ZIP을 압축 해제하세요.
  2. 크롬 주소창에서 chrome://extensions를 여세요.
    엣지는 edge://extensions를 사용합니다.
  3. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 선택하세요.
  4. manifest.json이 들어 있는 폴더를 선택하고, 디시 글쓰기 페이지를 새로고침하세요.

설치한 폴더는 삭제하지 마세요. 이 배포 방식에서는 업데이트 파일을 직접 교체해야 합니다.

이미지 넣기

  1. 본문에서 이미지를 넣을 위치를 선택하세요. HTML 모드는 꺼 주세요.
  2. Postimages 이미지 업로드를 누르고 새 창에서 파일을 선택하세요.
  3. 이미지가 들어오면 내용을 확인하고 디시의 인증·등록 절차를 진행하세요.

알아둘 점

이미지는 Postimages에 저장되며 링크를 아는 사람이 볼 수 있습니다. 디시 로그인·인증·최종 등록은 디시 화면에서 진행합니다. 확장은 로그인 쿠키나 비밀번호를 수집하지 않습니다.

PC용이며 모바일 앱·웹과 글 수정 화면은 지원하지 않습니다. 외부 이미지가 게시 후에도 표시되는지는 디시 정책에 따라 달라질 수 있으며 실제 게시 검증은 남아 있습니다. Postimages의 용량 제한과 이용 정책이 적용됩니다.

디시인사이드·Postimages와 제휴하지 않은 비공식 도구입니다.
