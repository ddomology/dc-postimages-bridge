# 안내 이미지

v1.0.1 화면 기준입니다.

2026-10-22 브라우저에서 직접 캡처한 화면입니다. UI를 합성하거나 편집한 이미지가 아닙니다. 화면의 해당 영역만 캡처했습니다.

- `dc-editor.jpg`: 디시 특이점이 온다 갤러리의 공개 PC 글쓰기 화면. 확장프로그램 설치 전 상태. https://gall.dcinside.com/mgallery/board/write/?id=thesingularity
- `postimages-upload.jpg`: Postimages 공식 게시판 업로드 팝업. 한국어·어두운 테마, 파일 선택 전 상태. https://postimages.org/upload
- `helper-panel.jpg`: 배포 중인 `extension/content.js`를 실제 디시 Summernote 파일과 함께 로컬에서 실행한 이미지 업로드 버튼과 직접 링크 메뉴. 실제 디시 페이지에 확장을 설치한 캡처는 아니며 페이지에서도 구분해 표시합니다.

업로드나 게시 성공을 입증하는 캡처는 아닙니다.
