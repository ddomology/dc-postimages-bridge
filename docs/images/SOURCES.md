## 업로드 GIF

`upload-demo.gif`와 `upload-demo-poster.png`는 2026-10-22 촬영했습니다. GIF는 실제 화면 캡처 7장을 12.5초로 편집한 시연이며 연속 화면 녹화는 아닙니다.

- 이미지: 짚쨩을 참고해 새로 생성한 테스트 이미지. 사용자 요청에 따라 `C:\UploadDemo\jipchan.png`에 저장했습니다.
- 폴더: Windows 탐색기에서 해당 폴더와 파일 선택을 직접 촬영했습니다. 업로드 파일 대화상자 캡처는 아니며, GIF 안에도 ‘탐색기’로 표시했습니다. 탐색기 바깥의 다른 창은 제외하고 왼쪽 탐색 목록은 불투명 마스킹했습니다.
- 업로드: 공식 Postimages 파일 선택 화면과 해당 PNG의 실제 전송 진행 상태를 내장 브라우저에서 캡처했습니다.
- 본문: 배포 중인 v1.0.4 `extension/content.js`와 디시의 실제 jQuery·Summernote 파일을 사용하는 로컬 편집기입니다. 업로드 결과나 이미지 삽입을 모의하지 않았습니다. 내장 브라우저가 추적하지 못한 팝업의 주소를 별도 탭으로 열었고, 확장의 기존 BroadcastChannel 경로로 실제 업로드 결과를 받았습니다.
- 편집: 영역 자르기·크기 조정·설명 자막·탐색 목록 마스킹만 적용했습니다. 편집기에는 시연용 이미지 표시 높이 제한을 적용했습니다. 실제 디시 페이지의 설치·최종 게시 성공을 입증하는 영상은 아닙니다.
