디시 이미지 브릿지 v1.0.3

설치
1. ZIP을 압축 해제합니다.
2. Chrome은 chrome://extensions, Edge는 edge://extensions를 엽니다.
3. 개발자 모드를 켭니다.
4. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
5. manifest.json이 들어 있는 폴더를 선택합니다.
6. 디시 글쓰기 페이지를 새로고침합니다.

사용
글쓰기 화면을 열면 기본 말머리 안내문만 자동으로 정리합니다.
1. HTML 모드를 끄고 본문에서 이미지가 들어갈 위치를 선택합니다.
2. '이미지 업로드'를 누르고 새 창에서 파일을 선택합니다.
3. 본문을 확인한 뒤 디시에서 글을 등록합니다.

자동 삽입이 안 되면 '직접 링크로 넣기(자동 삽입이 안 될 때)'를 엽니다.
Postimages 직접 링크 또는 포럼용 핫링크를 붙여 넣고 '본문에 넣기'를 누릅니다.

업데이트
작성 중인 본문이 있으면 먼저 복사해 보관하세요.
새 ZIP으로 기존 폴더의 파일을 교체합니다.
확장 관리 화면에서 새로고침한 뒤 디시 페이지도 새로고침합니다.
설치 폴더는 삭제하지 마세요.
